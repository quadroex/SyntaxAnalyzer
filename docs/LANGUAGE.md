# Підтримана мова MiniCpp

| Частина | Можливості |
|---|---|
| Типи | `int`, `double`, `bool`, `void` для результату функції |
| Змінні | Локальні змінні, початкові значення, кілька оголошень, вкладені області видимості |
| Масиви | Один вимір, `int`, `double`, `bool`, списки початкових значень, індекси, передавання у функції |
| Арифметика | `+`, `-`, `*`, `/`, `%`, унарні `+` та `-`, дужки |
| Порівняння | `<`, `>`, `<=`, `>=`, `==`, `!=` |
| Логіка | `!`, `&&`, `||` з коротким замиканням, умовний оператор `?:` |
| Перетворення | Неявні числові перетворення й явні приведення `(int)`, `(double)`, `(bool)` |
| Присвоєння | `=`, `+=`, `-=`, `*=`, `/=`, `%=` |
| Зміна на одиницю | `++` і `--` як окремі команди або частини `for` |
| Керування | `if/else`, `while`, `do/while`, `for`, `break`, `continue`, `return`, порожні команди |
| Функції | Визначення, прототипи з іменованими параметрами, виклики, рекурсія |
| Виведення | `std::cout`, `std::endl`, рядкові літерали, значення виразів |
| Введення | `std::cin` для числових змінних та елементів масивів |
| Допоміжний синтаксис | `#include <iostream>`, `using namespace std;`, коментарі |

Це підмножина C++, а не повна реалізація стандарту. Багатовимірні масиви, вказівники, глобальні змінні, структури, класи, шаблони, перевантаження функцій, `switch`, побітові операції та загальний препроцесор не підтримуються. Рядки доступні лише як літерали для виведення.

Розмір масиву задається десятковою цілою константою від 1 до 4096, наприклад `int values[5];`. Також підтримано визначення розміру зі списку, наприклад `int values[] = {3, 1, 4};`. У списку ініціалізації заборонені звужувальні перетворення C++. За потреби можна записати явне приведення типу.

Для масиву зі списком початкових значень незадані елементи отримують нулі. Масив без ініціалізації потрібно заповнити перед читанням. Індекси мають бути цілими й належати межам масиву. Параметр `int values[]` надає функції доступ до того самого масиву, тому зміни його елементів видно після повернення. Тип елементів аргументу повинен збігатися з типом параметра.

Записи `int a[2][3];` та `int a[2][3][4];` відхиляються як непідтриманий синтаксис. Цю версію свідомо обмежено одним виміром.

Присвоєння та інкременти доступні як команди й частини `for`. Наприклад, `x = x + 1;` підтримується, а `y = (x = 1);` не підтримується. Порівняння й логічні вирази у виведенні треба брати в дужки, наприклад `std::cout << (a < b);`, відповідно до пріоритетів операторів C++.

Умовний оператор у виведенні також потребує дужок, наприклад `std::cout << (a > b ? a : b);`. Під час виконання обчислюється лише вибрана гілка. Цикл `do/while` виконує тіло хоча б один раз, а `continue` переходить до його умови.

Для `cin` дані заздалегідь записуються у поле `Program input for cin`. Числа розділяються пробілами або новими рядками. Для `int` потрібен цілий десятковий запис, для `double` дозволено дробовий та експоненційний запис, для `bool` дозволені `0` і `1`. Кожен елемент вводу має повністю відповідати числовому запису. На неправильних даних або їхній нестачі середовище зупиняє виконання з повідомленням. Повна поведінка станів помилок потоку стандартного C++ не моделюється.

Функцію потрібно оголосити або визначити перед викликом. Кожна оголошена функція повинна мати визначення у цьому самому файлі. Програма повинна містити `int main()` без параметрів. Виклики `main` заборонені.

Числа записуються у десятковій формі без суфіксів. Дробові числа також допускають експоненційний запис. Тип `int` має 32 біти зі знаком, `double` використовує двійкові числа подвійної точності, `bool` зберігає логічне значення. Для арифметики `bool` підвищується до `int`. Цілочисельне ділення відкидає дробову частину в напрямку нуля. Виведення `double` використовує шість значущих цифр, а `bool` виводиться як `0` або `1`.

Підтримані escape-послідовності у рядках - `\n`, `\r`, `\t`, `\\`, `\"`, `\'`. Заголовок `iostream` розпізнається як дозволена директива, сам вміст стандартної бібліотеки не розбирається.

Виконавець повідомляє про ділення на нуль, переповнення `int`, нечислові чи нескінченні результати та читання неініціалізованих змінних. Це явні діагностики навчального середовища. Не всі такі випадки мають гарантований результат у звичайному C++.

Межі роботи - по 32768 байтів вихідного тексту й даних вводу, глибина AST до 256, 100000 кроків виконання, 128 активних викликів, 65536 зарезервованих елементів масивів у активних викликах і 65536 байтів виведення. Операнди та аргументи обчислюються зліва направо. У присвоєнні спочатку обчислюється права частина, потім місце запису. Індекс елемента обчислюється один раз. Звичайний C++ у частині інших випадків допускає інший порядок, тому приклади для порівняння не покладаються на нього.
