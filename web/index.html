Supported language

int, double, bool, void functions, local variables, one-dimensional arrays, arithmetic, comparisons, logical operations, casts, conditional expressions, if/else, while, do/while, for, break, continue, return, function calls, recursion, std::cout and std::cin.

Use decimal numbers, function definitions or prototypes, #include <iostream> and optional using namespace std. Assignment and increment are statements or for clauses.

Array sizes are decimal constants from 1 to 4096. Arrays can be initialized with a list and passed to functions. Multidimensional arrays, pointers, classes, global variables and general preprocessing are outside this subset.

  1. Flex recognizes keywords, identifiers, numbers and operators using regular expressions in lexer.l.
  2. Bison uses grammar rules in parser.y and LALR(1) tables to build the AST.
  3. The semantic pass resolves names, checks types and assigns a unique symbol to every declaration.
  4. The C++ interpreter visits AST nodes and executes the program.
  5. The generator visits the same AST and emits JavaScript with numeric conversions.
  6. The browser draws the AST with JavaScript and SVG. Generated code runs in a separate Web Worker.
